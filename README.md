

# 👨‍💻 About Me

I’m Rafael, a 20 year-old Computer Science student based in Portugal. My main focus is on Full-Stack Web Development, with a strong emphasis on UI/UX. I enjoy the technical challenge of building reliable backend systems, but I am equally passionate about designing clean, intuitive interfaces that provide a great user experience. 

Currently, my goal is to finish my Bachelor's degree and pursue a Master's to further deepen my technical skills. I like working on practical projects that solve real-world problems—such as helping local businesses go digital—and I am always looking to learn new technologies along the way. Feel free to reach out if you want to connect!
